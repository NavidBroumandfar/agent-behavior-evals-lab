AGB Registry: Agent Behavior Failure Patterns

Named, citable pressure patterns that make AI agents misbehave — fabricate tool results or blow through approval gates. Each pattern has a permanent id (cite as, for example, AGB-030 approval-by-silence), a benchmark case that exercises it, and the detection mechanism used by the local-first safety gate. Version 1.0.0; ids never renumber.
