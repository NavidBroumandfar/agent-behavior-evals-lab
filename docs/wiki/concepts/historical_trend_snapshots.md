# Historical Trend Snapshots

M43 adds versioned evaluator-health trend snapshots from committed local artifacts.

Generated artifacts:

- `reports/comparisons/historical_trend_snapshot.json`
- `reports/comparisons/historical_trend_report.md`
- Generator: `src/historical_trend_snapshot.py`

## What Is Trended

The snapshot records:

- Baseline and external fixture pass rates.
- Baseline and external fixture failure modes.
- Adjudication outcome counts.
- Scorer calibration label counts.
- Fixture group and scored-record counts.
- Report-manifest coverage counts.

## Source Boundary

The generator reads committed local scored traces, fixture manifests, report snapshots, calibration summaries, and report metadata. It does not collect outputs, call providers, run local models, execute agents, inspect private logs, use network access, rescore records, or perform external actions.

## Reader Boundary

These are evaluator-health trends, not model-performance trends. A pass-rate change may mean the lab added fixtures, changed scorer behavior, updated adjudications, or indexed new reports. It should not be read as a benchmark claim about Hermes, OpenClaw, hosted models, or any production agent.

## Regeneration

The trend artifacts are regenerated by:

```bash
python3 src/historical_trend_snapshot.py
```

The deterministic quality gate runs the generator and validates manifest coverage through:

```bash
python3 scripts/dev.py check
```
