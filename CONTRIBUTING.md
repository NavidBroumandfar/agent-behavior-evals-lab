# Contributing

Changes should improve this public saved-trace evaluator or its synthetic examples. Do not submit credentials, customer data, private traces or proprietary scenario-authoring material.

Use Python 3.10 or later. No third-party dependency is required for the evaluator or tests.

Run `python3 scripts/dev.py check` before proposing a change. Optional linting is available through `python3 scripts/dev.py lint` when Ruff is already installed.
