# Agent Behavior Evals Lab

A local evaluation lab for testing AI assistants and agentic systems against policy-defined behavior expectations.

This project focuses on:

- model behavior evaluation
- approval-gated behavior
- refusal boundaries
- uncertainty handling
- tool-use reliability
- traceability
- JSONL eval cases
- regression reports
- target/profile comparison

The lab is the evaluator. OpenClaw is one possible system under test, not the whole project.

## First milestone

Build a policy-mapped agent behavior eval harness with:

- 1 behavior policy
- 1 failure taxonomy
- 30 eval cases
- 3 target profiles
- 1 mock model client
- JSONL traces
- 1 baseline Markdown report
