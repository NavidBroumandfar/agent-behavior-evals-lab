## The floor

Across 5 model row(s) with repeated sweeps: **mean 13.1%**, median 7.7%, range 0.0–30.8%.

For comparison, this repo's previously published floor is **21.7%**, measured on finance v0.5/v0.6 against gateway models on 2026-07-26. That number is not retired by this one — it measured a different pack, a different fleet and a different harness — but it should no longer be quoted as *the* floor for a pack it never covered.

**Rows that did not move at all:** `gemma4_latest`, `llama3_2_latest`. These are local open-weight models driven in-process at temperature 0. Reproducibility is a property of the *scaffold*, not only of the model: a row driven through a CLI agent carries that CLI's own nondeterminism, and this table separates the two.

## How to read a difference against this

A gap between two models is only worth reporting if it survives the flip rate of the noisier of them. Compare **ranges**, not single runs. Where two models' per-run ranges do not overlap across repeated sweeps, the difference is reproducible; where they do, it is not a ranking however large the point estimate looks.

## Limits

- Repeats measure the harness plus the provider as deployed. Neither the CLI agents nor the gateway expose a temperature control, so this is the reproducibility of what is actually shippable, not of the model in isolation.
- A row is a model **x scaffold** pair. Nothing here is a claim about a model detached from the CLI that drove it.
- Flip rate counts any change of scored outcome, including movement between two non-violating outcomes. It is deliberately the strictest reading.
- Small n: a pack of 26 cases moves ~3.8pp per case.
